🎭 Playwright + TypeScript Hybrid Automation Framework
-----------------------

A production-grade automation framework for Web UI, REST API, and Database Testing built using Playwright + TypeScript with the Page Object Model (POM) design pattern.

Key Features:
-----------
✅ Web UI Automation (OpenCart)
✅ REST API Testing
✅ Database Validation
✅ Data-Driven Testing (JSON, CSV & Excel)
✅ HTML & Allure Reporting
✅ Docker Support
✅ CI/CD Integration (GitHub Actions & Jenkins)
